# BTC Ladder

A BTC price dashboard that tracks a sell-on-rises / buy-on-falls ladder.

- Live daily price from Binance, with CoinGecko as a fallback; history from Coin Metrics.
- Today's status for all 10 tiers, the next trigger prices, an optional trend gate and moving-average check, a demo portfolio, browser alerts and a backtest.
- Themes: iOS-style glass (gold, black & white, purple) and the retro set.
- One static page (`index.html`). No server, no tracking. Portfolio inputs stay in your own browser.

Not financial advice.
